# Skin Atelier editorial assets

This folder is reserved for GlowSkin's approved, original AI-generated luxury editorial images.

The source images are distributed as an optimized WebP pack alongside PR #24 in the ChatGPT conversation. The GitHub integration cannot transfer binary image files, so the images must be uploaded to this folder on the PR branch before merging.

Expected filenames:
- `atelier-hero-wide.webp`
- `atelier-home-portrait.webp`
- `atelier-skin-concerns.webp`
- `atelier-ingredients.webp`
- `atelier-products.webp`
- `atelier-journal-wide.webp`

The frontend's `AtelierImage` component uses a locally available photo as a fallback when the original generated asset has not yet been uploaded.

These images depict AI-generated people and skin details. They are visual illustrations, not photographs of real patients, clinicians, or customers; they do not establish the efficacy of any product.
